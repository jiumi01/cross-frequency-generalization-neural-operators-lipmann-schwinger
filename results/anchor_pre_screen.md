# 锚定路线：零 GPU 预检与基线记录

作者：Longgang Wang（洛阳理工学院）。本文件是 `code/prescreen_anchor.py` 与
`code/anchor_baseline.py` 两份测量的可读记录，是论文中锚定相关章节的数据来源。

## 1. 问题来源

C3b 臂（`eb_fno`）是整个判别链中决定性的一次测量：在带外把校正场**能量**强行
锚定到一阶 Born 场上，能量比确实被拉起（f=12 处 0.122 → 1.596），但对**齐度**
塌到 0.012，误差反而变差（ε(5) 1.117 → 1.664，平台 0.963 → 1.755）。

结论：训练好的算子缺的不是带外**能量**，而是带外**相位**。Born 级数是本问题中
唯一"任意频率解析可算、相位天然正确"的对象，因此自然的补救是让网络不去臆造那
部分，而是把它作为锚点：

$$\hat u = a B_1 + b B_2 + r_\theta(v,\psi_{\rm inc},f,B_1,B_2)$$

其中 $a,b$ 为两个复系数（4 个实数），仅在带内训练；$B_1,B_2$ 为入射场的前两阶
Born 校正（`code/data.py:anchor_terms`，FFT 可得，无求解、无标签）。

## 2. 预检（128 样本探针网格，4 个对比度）

`code/prescreen_anchor.py`，纯 CPU。仅用带内数据拟合 1–2 个复尺度，测零样本带外
误差。预登记规则：v_max=0.25 处"带外锚定误差 / 平凡基线 ≤ 0.5"为 GO-STRONG。

| v_max | 一项锚定 αB₁（带内→带外） | 二项锚定 αB₁+βB₂（带内→带外） | 平凡基线（带外） |
|---|---|---|---|
| 0.05 | 0.158 → 0.140 | 0.022 → 0.025 | 0.204 |
| 0.10 | 0.306 → 0.261 | 0.080 → 0.087 | 0.397 |
| 0.25 | 0.582 → 0.497 | 0.299 → 0.313 | 0.858 |
| 0.50 | 0.747 → 0.661 | 0.538 → 0.544 | 1.266 |

一项锚定在 v=0.25 的比值 0.58 差阈值 0.08；把锚定对象加强为二项（加二阶 Neumann
项，仍为零样本）后比值 0.36，达标。**动的是锚定对象，不是阈值。**

预检的关键签名不是"低"，而是"平"：锚定误差在带内带外几乎相同，而训练好的 FNO
是 0.0716 → 0.963（13.4×）。

## 3. 基线（论文自身评估协议）

`code/anchor_baseline.py`，纯 CPU。n=200，频率点用 seeds 60000+vi、带内用
70000+vi，5 个对比度；$a,b$ 在各自训练缓存（`train_a005/a010/a025/a050/a100`）
前 512 个样本上最小二乘拟合——拟合数据不含任何测试样本、不含任何带外频率。

| v_max | 带内 | ε(4) | ε(5) | 平台 (f≥6) | 平凡平台 | 原始 Born₁ 平台 |
|---|---|---|---|---|---|---|
| 0.05 | 0.022 | 0.021 | 0.022 | 0.023 | 0.228 | — |
| 0.10 | 0.083 | 0.074 | 0.072 | 0.077 | 0.425 | — |
| 0.25 | 0.338 | 0.282 | 0.280 | **0.300** | 0.901 | 1.188 |
| 0.50 | 0.590 | 0.523 | 0.539 | 0.579 | 1.334 | — |
| 1.00 | 0.749 | 0.679 | 0.702 | 0.703 | 1.645 | — |

v_max=0.25 对照：训练好的 FNO 带内 0.0716、平台 0.963、$r=\varepsilon(5)/\varepsilon(4)=7.48$；
锚定带内 0.338、平台 0.300、$r=0.99$。锚定平台比训练好的算子低 **3.2×**，比平凡
基线低 **3.0×**，且**悬崖特征消失**。

两者互补：网络在带内赢 4.7×，锚定在带外赢 3.2×。加法形式（锚定作为先验而非仅作
为输入通道）正是为了让一个臂同时持有两者——若学习到的残差在带外塌缩（C3b 测得的
失败模式），剩下的仍是锚定，而不是入射场。

## 4. 代价与判读

- 参数代价：10.252586M → 10.252746M（+160）+ 4 个复系数 = **+164（0.0016%）**，
  容量不构成解释（与 C2 臂同纪律）。
- 预登记三档判读（`code/run_ba1.py`）：
  - PASS：带外均值 < 0.6 且 $r<2$——残差可迁移，补救构成方法；
  - PARTIAL：带外不优于也不劣于锚定地板 0.300——锚定即补救，残差为负结果；
  - FAIL：带外差于地板——残差在相位正确的锚定上叠加噪声，如实报告并将主张
    收窄到锚定本身。

## 5. 复现

```
python code/prescreen_anchor.py     -> results/prescreen_anchor.json
python code/anchor_baseline.py      -> results/anchor_baseline.json
python code/run_ba1.py --go         -> 3 种子锚定臂（需 GPU）
```
